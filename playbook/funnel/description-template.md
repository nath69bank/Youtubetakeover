# Description, pinned comment and end screen

Set the description as the **upload default** in YouTube Studio → Settings → Upload
defaults, then edit per video.

## Description template

```
👉 FREE [LEAD MAGNET NAME]: https://www.wirral.ai/free/[slug]?utm_source=youtube&utm_medium=description&utm_campaign=v0XX

[2–3 sentences in plain English: who this video is for, the problem, what they'll
be able to do after. Put the main search phrase in the first sentence.]

In this video:
00:00 [Hook / the problem]
00:40 [Section 1]
03:15 [Section 2]
05:10 [Section 3]
06:45 [Section 4]
08:45 [The payoff]

💬 Want us to look at your business? Message us on WhatsApp: https://wa.me/447368349702
🌐 wirral.ai: AI consulting, implementation, automation, websites & SEO for UK businesses
📍 Based in Widnes, working across Wirral, Liverpool, Manchester, Chester, Warrington & North Wales

▶️ Watch next: [title] [link]
📚 Playlist: [pillar playlist link]

Links mentioned:
- [tool / article]: [link]

[Affiliate disclosure if any links are affiliate: "Some links above are affiliate
links. We may earn a small commission at no cost to you. We only link tools we use."]

#[topic] #smallbusinessuk #[town]
```

**Notes**
- Keep line 1 as the CTA, since only ~2 lines show before "…more".
- Chapters (timestamps) need to start at 00:00 and have at least 3 entries.
- Max 3 hashtags; they show above the title.

## Pinned comment template

```
📥 Grab the free [lead magnet] here → https://www.wirral.ai/free/[slug]?utm_source=youtube&utm_medium=pinned&utm_campaign=v0XX

Question for you: [one specific question tied to the video, e.g. "Which of the
4 steps is hardest for your business?"]. I read and reply to every comment.
```

## End screen (last 20 seconds)

- **Left:** "Best for viewer" video, or a specific next video in the series
- **Right:** Subscribe element
- Keep talking over the end screen: the CTA line from [cta-scripts.md](cta-scripts.md).

## Cards

- Add 1 card at the moment the topic connects to another video.
- Add 1 card linking to the matching playlist around 70% through.
